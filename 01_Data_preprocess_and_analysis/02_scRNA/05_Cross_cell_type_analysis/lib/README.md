# lib/

The files `misc.R` and `heatmaps.R` in this directory were retrieved from the
EcoTyper source code (https://github.com/digitalcytometry/ecotyper,
`ecotyper/pipeline/lib/`; Luca et al., Cell 2021, doi:10.1016/j.cell.2021.09.014)
and are used unmodified by `01_EcoTyper_adapted.R`.
